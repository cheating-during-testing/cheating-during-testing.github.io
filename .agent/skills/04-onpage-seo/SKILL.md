# Game On-page SEO Skill

## 默认规则

- Title 目标 <=60
- Description 目标 <=160
- 1 H1
- 首页 >=1200 words
- 子页 >=800 words
- Primary keyword：Title / H1 / first100Words / 核心 H2
- density 目标 2%～3%，以自然表达为先
- 首页到全部 P0/P1
- 子页回首页
- 子页到 1～3 个相关页面

## H 结构

H2 必须来自：
- Search Intent
- Fact Pack
- 真实玩家问题

禁止通用 AI H2 堆叠。

## 输出

每页：
- keyword mapping
- metadata
- H structure
- min/target words
- required placement
- density target
- internal links
- anchor plan
- source requirements
