# 搜索需求分析规则

## 输入只来自已有数据

允许：

- 主游戏名
- DataForSEO 主词 search volume
- Google Ads 关键词扩展结果
- Google Trends related top/rising
- Google Autocomplete（兜底）

禁止：自己创造“看起来玩家会搜”的词加入事实数据。

## 聚类方法

把表达同一目标的词合并：

```text
game pets
game best pets
game pet tier list
→ 宠物/最佳宠物需求
```

```text
game codes
new game codes
game codes august
→ 兑换码需求
```

## 页面独立性判断

建议独立页面：

- 多个真实关键词围绕同一明确需求
- 搜索量/上涨信号相对突出
- 页面能够独立解决一个玩家问题

建议合并：

- 只是同义词
- 搜索量很小且内容高度重叠
- 拆页会造成内容重复

## 输出必须回答

1. 玩家为什么搜这个游戏？
2. 主要需求按重要性是什么？
3. 哪些需求值得独立页面？
4. 哪些词应合并？
5. 哪些看似相关但不应该做？
