# 趋势与 DataForSEO 规则

## 趋势

核心抓“长期低位 + 最近突破”。

不要只看：

- 单点 100
- 最近一周比上一周高
- 一次异常尖峰

要组合：

- history low ratio
- recent peak
- growth ratio
- up moves
- recent breakout

`missing_data=true` 不参与核心判断。

## 搜索量

`search_volume` 是规模参考。

新词可能 null/滞后，因此：

`strong_rising + search_volume null` 不能自动淘汰。

## Google Ads competition

是广告竞争，不是 SEO KD。
